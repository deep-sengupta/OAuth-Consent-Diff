# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in OAuth Consent Diff, please report it responsibly.

Please do not publicly disclose the vulnerability before it has been reviewed.

Open a private GitHub security advisory or contact the repository maintainer with:

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- A proof of concept, if available
- Any suggested remediation

## Scope

Security reports related to OAuth consent detection, permission analysis, trusted baselines, extension messaging, storage, and data handling are welcome.

Thank you for helping improve the security of OAuth Consent Diff.
