# Contributing

Contributions to OAuth Consent Diff are welcome.

## How to Contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes and add tests where appropriate.
4. Verify that existing tests continue to pass.
5. Open a Pull Request against `master`.

## Pull Requests

Please keep changes focused and provide a clear description of:

- What was changed
- Why it was changed
- How it was tested

For security vulnerabilities, please follow the process described in `SECURITY.md` instead of opening a public issue.

Thank you for contributing to OAuth Consent Diff.
